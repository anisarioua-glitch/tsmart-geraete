ABB EQmatic Zähler verbinden

Erfahren Sie, wie Sie Ihren ABB EQmatic Zähler schnell und sicher in thermondo smart einrichten.

1. Überblick

Diese Anleitung beschreibt die Integration der folgenden Geräte in das System thermondo smart:

  • ABB EQmatic als Energiemessung
  • ABB EQmatic als Produktionsmessung
  • ABB EQmatic als Smart Meter
⚠️
Wichtiger Hinweis: Dieser Zähler kann nicht für die ZEV-Funktion (Zusammenschluss zum Eigenverbrauch) genutzt werden.

2. Voraussetzungen

💡
Die Integration dieses Zählers kann erweiterte Netzwerkkenntnisse benötigen. Es wird Laien nicht empfohlen, dies selbst durchzuführen.

Stellen Sie sicher, dass folgende Voraussetzungen erfüllt sind, bevor Sie mit der Einrichtung beginnen:

  • Der ABB EQmatic Zähler ist im selben Netzwerk wie Ihr thermondo smart Gateway installiert.
  • Sie haben Zugriff auf die Weboberfläche des EQmatic Zählers über einen Webbrowser.

3. Einstellungen am EQmatic Zähler

Über die Weboberfläche des Zählers müssen Sie die folgenden Werte aktivieren oder kopieren:

  1. Autorisierungstoken: Navigieren Sie zu Ihrem Benutzerprofil und öffnen Sie die Registerkarte "Autorisierungstoken". Aktivieren Sie dort die EQmatic API-Token-Authentifizierung und kopieren Sie den Token.
  2. Seriennummer: Kopieren Sie auch die Seriennummer des Zählers.
  3. SSL-Zertifikat: Das SSL-Zertifikat muss für das gesamte Subnetz aktiviert werden.
  4. Software: Stellen Sie sicher, dass der Zähler auf dem aktuellsten Softwarestand ist.

Interaktive Anleitung: Token aktivieren

Hinweis: Die Animation wird aufgrund Ihrer Systemeinstellungen nicht abgespielt. Der Endzustand ist unten dargestellt.

Bereit. Klicken Sie auf "Ablauf starten", um die Schritte zu sehen.

4. Integration in thermondo smart

  1. Wählen Sie in thermondo smart die Kategorie, in der der Zähler erfasst werden soll: "Geräte" -> "Energiemessung", "Wechselrichter" oder "Smart Meter".
  2. Um den Zähler zu verbinden, geben Sie neben der IP-Adresse des Geräts auch die zuvor kopierten Werte ein.
ℹ️
Hinweis: Bei diesem Gerät kann die Registernummer, die abgefragt werden soll, je nach Installation konfiguriert werden. Tragen Sie hier die konfigurierte Registernummer für die verbrauchte Leistung ein.

Eintragungsfelder in thermondo smart

Eingabefeld Bedeutung / Herkunft
IP-Adresse Die lokale Netzwerk-IP-Adresse Ihres ABB EQmatic Zählers.
Autorisierungstoken Der aus dem Benutzerprofil des EQmatic kopierte API-Token.
Seriennummer Die eindeutige Seriennummer Ihres EQmatic Zählers.
Registernummer Die in Ihrer Installation konfigurierte Registernummer für die verbrauchte Leistung.

5. Verbindung prüfen

Sobald Sie alle Daten in thermondo smart eingetragen und gespeichert haben, prüft das System die Verbindung:

  • Achten Sie auf das Statussymbol in der thermondo smart Übersicht.
  • Ein grünes Symbol signalisiert eine erfolgreiche Datenübertragung.
  • Werden keine Werte angezeigt, prüfen Sie die Netzwerkeinstellungen und ob das SSL-Zertifikat korrekt für das Subnetz freigegeben ist.

6. Hilfe & Fehlerbehebung

Häufige Probleme und Lösungen

Problem: Der Token lässt sich nicht aktivieren.

Lösung: Stellen Sie sicher, dass Sie mit einem Administrator-Konto auf der Weboberfläche des EQmatic angemeldet sind. Einfache Benutzerkonten haben eventuell nicht die Berechtigung, API-Token zu generieren.

Problem: Keine Verbindung trotz korrektem Token.

Lösung: Prüfen Sie, ob das SSL-Zertifikat für das gesamte Subnetz freigegeben ist. Wenn das Gateway von thermondo smart in einem anderen Subnetz liegt, kann die SSL-Verschlüsselung die Verbindung blockieren.

Problem: Falsche Messwerte werden übertragen.

Lösung: Überprüfen Sie die eingetragene Registernummer. Da diese je nach Installation variieren kann, muss sie exakt mit der im EQmatic für die verbrauchte Leistung konfigurierten Nummer übereinstimmen.
